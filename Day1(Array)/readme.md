Question1:-

Problem Statement(two sum II)
You are given a 1-indexed array of integers numbers sorted in non-decreasing order and an integer target.

Find two numbers in the array whose sum is equal to target.
- Return the indices of these two numbers as an integer array [index1, index2].
- The indices must be 1-based, not 0-based.
- The first index must be smaller than the second index.
- You cannot use the same element twice.
- Exactly one valid solution exists.

test case 1:-

numbers = [2, 7, 11, 15]
target = 9

[1, 2]

test case 2:-

numbers = [2, 3, 4]
target = 6

[1, 3]
